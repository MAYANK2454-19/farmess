# Copy market search links

The farmer Market Prices page provides a **Copy share link** action. It copies the current page URL, including the applied commodity, location, date, modal-price and sort criteria already represented in the URL.

Only applied criteria are included. Unsubmitted search and advanced-filter drafts are not copied. The recipient's page loads market observations from the configured source when opened, so results can change over time and may differ when source access or available observations differ.

The action reports whether the browser copied the link. If clipboard access is unavailable or denied, the page tells the user to copy the URL from the browser address bar instead.
