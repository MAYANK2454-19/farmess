# Printable Market Observation Report

The Market Prices explorer provides **Print / Save PDF** alongside CSV export.

- The report uses the currently loaded source result, applied advanced date/price filters and selected sort order.
- The browser print dialog can send the report to a printer or save it as a PDF.
- The report retains the visible market snapshot, source-quality context, forecast context and observation cards where present.
- Search/filter controls and interactive sorting controls are omitted from the print layout.
- Source resource URLs are printed beside their links so a paper/PDF copy retains provenance.

This is a client-side presentation feature. It does not create server-side files, change source records, or claim that reported observations are live quotes or guaranteed sale prices.
